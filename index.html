DSL-LLaDA: Scaling Continuous Denoising to 8B Masked Diffusion LMs

DSL-LLaDA lightly adapts LLaDA-8B-Instruct with Discrete Stochastic Localization so masked diffusion language models can denoise in continuous embedding space before committing to final tokens.

Method

Instead of training a continuous language diffusion model from scratch, DSL-LLaDA converts a pretrained masked DLM into a continuous denoiser with a short continuation run.

Soft noisy token states

Binary clean-or-mask inputs are replaced with continuous Gaussian-noised token embeddings that encode graded uncertainty.

No architecture change

A softmax converter maps DSL states back into the LLaDA input space, keeping the pretrained backbone intact.

Continuous SDE sampling

Response positions evolve jointly in embedding space and commit to hard tokens only at the final decoding step.

Main findings

The paper studies low-step generation, summarization, and noisy-state robustness against same-compute discrete controls.

Better low-NFE behavior

Continuous inference reduces the premature-termination and repetition tradeoff seen in iterative unmasking.

Strong summarization

At low forward-pass budgets, DSL-LLaDA-SDE improves zero-shot summarization quality across the evaluated benchmarks.

Selective correction

Continuous-noise exposure helps the model correct corrupted tokens while preserving clean context tokens.

Quick start

The repository keeps paper-only assets out of the release and points model weights to Hugging Face. 

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

mkdir -p checkpoints
huggingface-cli download liddlefish/DSL-LLaDA-Beta1 \
  --local-dir checkpoints/DSL-LLaDA-Beta1 \
  --local-dir-use-symlinks False

export DSL_LLADA_REGISTRY=dsl_llada/configs/registry_hf_beta1.template.json
